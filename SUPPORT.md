# Support

Airlock is a volunteer-maintained **first public beta** ([`v0.1.0-beta.1`](CHANGELOG.md)). Expect rough edges; APIs and discovery coverage may change before 1.0.

| Need | Where |
|------|--------|
| Bug / feature | [GitHub Issues](https://github.com/ankittk/airlock/issues) — include `airlock version`, OS, and a minimal repro |
| How-to / design | GitHub Discussions (when enabled) or an issue labeled `question` |
| Security | [SECURITY.md](SECURITY.md) only |
| Contributing | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Release notes | [CHANGELOG.md](CHANGELOG.md) |

There is **no SLA** and no commercial support contract for the OSS CLI today. Paid / hosted offerings — if any — will be documented separately and will not replace this free local CLI.
